#Misrak Coffee
A full-stack coffee ordering web application for browsing Ethiopian coffee products, managing a shopping cart, placing orders, and handling payments.

##  Features
### Customer Features
- Browse available coffee products
- View product details
- Add products to the shopping cart
- Increase or decrease item quantities
- Remove items from the cart
- View order totals
- Select a payment method
- Place orders
- Contact/enquiry form
- Responsive user interface
- Dark mode support

### Admin Features
- Admin dashboard
- Manage products
- Manage customer orders
- Update order status
- View and manage business data

## Tech Stack
### Frontend
- HTML
- CSS
- JavaScript
- Live Server
### Backend
- Node.js
- Express.js
- MySQL / MariaDB
- JWT Authentication
- REST API
